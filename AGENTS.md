# Project instructions

Use English for all public repository documentation, code comments, user-facing tool messages, commit messages, issues, pull requests and release notes. Conversations with the user may follow their preferred language.

Keep game dumps, tickets, keys, generated game code, diagnostic logs, device identifiers and compiled game binaries local and excluded from Git. Publish only tools, runtime source, identification metadata and documentation.

Describe verified behavior accurately. The current diagnostic reaches GX2Init; this is not a playable game or APK. Do not claim graphics, performance or gameplay compatibility without testing it.
